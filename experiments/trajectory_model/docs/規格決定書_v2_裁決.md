## 壹、τ 的可達性（§1 第一點）

**裁決：採 τ = 60 為主分析；τ = 14／30 的不可達本身列為結果。**

你觀察到的現象——鬆弛快時雜訊誘發提早逃逸，使 t_event − t_crit 中位對任何漂移速率
都壓在 90 天以內——在物理上是正確的，不需要修。它的意思是：

> 當系統回復得夠快時，翻轉會被雜訊觸發而非被分岔觸發，
> 於是「臨界日」與「事件日」塌縮在一起，預警窗口在原理上就不存在。

這是一句可以寫進結論的話，而且它把 τ 從自由參數變成一個有意義的條件：
**預警窗口是否存在，取決於系統的鬆弛時間尺度是否夠慢。**

實作要求：

- 主分析 τ = 60，並將滾動窗格點由 {14, 21, 28, 42} 改為 **{21, 42, 60, 90}**
  （v1 要求 τ 與窗長同量級，此處一併調整）
- τ 掃描曲線（`calibration.*.delta_mu.scan`）獨立出圖，作為結果圖之一
- 圖說須寫明：τ ≤ 30 時 t_event − t_crit 中位不超過 90 天，預警窗口塌縮

**不採用**「退回 FADE 等價 Δμ 1.55，3／12 個月改成 ×0.5／×2」這個折衷，
理由是 ×2 那格拉不進 C 目標，代表該格已離開合理參數空間，硬留著只會製造無法解讀的列。
改為在 τ = 60 底下重做三格校準（中位翻轉時程 3／6／12 個月），若仍有格達不到，
就把達不到的那格標為 `unreachable` 並在敏感度表中留白，不要用替代值填。

## 參、洩漏警訊：改變結局定義（§1 第三點）

**裁決：不接受「合法近端訊號」，改變結局定義。這是本次最重要的一項。**

你的觀察完全正確：結局由 x(t) 的門檻跨越定義，因此任何使用 x(t) 歷史的模型
在結構上必然大幅勝出。你的自查也已指出「軌跡資訊大幅提升排序」反而被支持——
也就是 H2 被推翻了。

但這個推翻是**假的**。它推翻的不是 H2，是我們自己造的一個恆真設定。
在真實世界裡，透析的啟動不是 eGFR 一跨過門檻就發生，而是一個機率性的臨床決策過程；
正因如此，Xu 2022 那類研究才會只得到 0.008 的 C 增益。
我們的設定把那個機率層拿掉了，於是增益被灌到虛高。

**修正方式：結局改為風險驅動（hazard-driven），不再是確定性門檻跨越。**

- 每日事件風險 λ(t) = λ₀ · exp(β · x(t))，即 x 只調節風險而不決定事件
- λ₀ 與 β 校準到使五年事件率落在合理區間（建議 15–30%），並使靜態 C 落在 0.65–0.75
- 門檻跨越日仍然記錄，改稱 `t_threshold`，作為描述性里程碑，**不再是結局**
- 於是三個時點並存：`t_crit`（μ 跨 μc）、`t_threshold`（x 跨門檻）、`t_event`（風險實現）

這樣 H2 才是一個公平的檢定。若修正之後 C 增益仍然很大，那才是真的發現；
若如預期落在 0.01 附近，H2 就得到支持。

實作要求：加一個單元測試，確認在 β = 0 時動態模型相對靜態模型無增益。

## 肆、雙尾警報規則（§1 第四點）

**裁決：區分「假設檢定」與「警報規則」，兩者用不同的尾。**

v1 禁止事項第 5 條的「一律雙尾」是針對**假設檢定**——比較翻轉型與爬升型的提前期時，
不預設哪一型較長，這一點不變。

但**警報規則**是另一回事。韌性流失的定義就是自相關上升，
讓下降也觸發警報在臨床上說不通，也會污染偽警報率。

實作要求：

- 主要警報規則：AR(1) 與 SD 的 Kendall τ **同時為正**且超過共同虛無分布的 95 分位（單尾上升）
- 另外獨立計數「下降型偏離」（τ 同時為負且超過 95 分位），
  **記錄並報告其發生率，但不計入主要提前期**
- 報告下降型的理由：既有研究曾報告躁症發作前變異度反而下降，
  若本模擬也出現一定比例的下降型偏離，值得寫入討論

如此既保留了不預設方向的誠實，也讓警報規則有臨床意義。

## 伍、置換虛無的意義（§1 第五點）

**裁決：接受你的實作，但必須在方法中明白寫出虛無假設的內容。**

時間打亂保留了水準與總變異，因此 p 值檢定的是「時間形狀是否帶有資訊」，
而不是「有沒有訊號」。這是正確的做法，也是這類分析的標準虛無。

實作要求：在方法章節與程式註解中明寫——

> 虛無假設為「該序列的時間順序不帶資訊」，非「該序列無變異」。
> 因此顯著的結果代表變化的**形狀**有意義，而非變化的**幅度**有意義。

這一句可以擋掉一整類誤讀。

## 捌、追加修正一：翻轉型的起始水準必須與線性型重疊（優先處理）

**這一項你沒列，但它會使 H1 失去意義。**

你的自查寫道：「各層型別組成完全由 x0 決定（翻轉型 x0 ≈ eGFR 90 → 全在低風險層）」。

若如此，則風險分層等於把兩型完全分開，於是任一風險層內幾乎只有一種型態，
H1（同一風險區間內存在多種型態）就不是被檢驗，而是被設定成偽。
分群 ARI 只有 0.1–0.5，部分原因可能也在此。

**修正要求**：

1. 翻轉型與線性型的 x₀ 必須自**同一個基線分布**抽取（KDIGO G2–G4）
2. 型別歸屬由潛在易感度決定，**不得由 x₀ 決定**
3. 加一個檢核：計算每一風險層內兩型的混合比例，
   若任一層的單一型別佔比超過 90%，程式須發出警告並停止，因為此時 H1 無從檢驗
4. 修正後重新報告分群 ARI；若 ARI 仍低，那才是真的「分群難以還原生成類別」的發現

臨床上這也比較真實：同樣是中度腎功能不全的人，有的緩慢下降，有的即將急轉直下，
兩者在基線上看不出差別——這正是本研究要講的事。

## 玖、追加修正二：μ 的漂移不得自第 0 天開始（優先處理）

**這一項你間接指出了——你說「絕對提前期 800 天來自 μ 從第 0 天漂移」——但沒有列為待修。**

若 μ 自第 0 天起即單調漂移，則臨界減速的訊號從第一天就存在，
提前期自然會膨脹到八百天這種臨床上無意義的數字。

**修正要求**：

1. 為每位翻轉型個案抽一個**隨機的漂移起始日** `t_drift_onset`，
   在此之前 μ 固定，序列為定態
2. `t_drift_onset` 的分布使漂移期長度落在數個月至兩年的量級，並寫入參數檔
3. 提前期一律以 `t_event` 為終點計算（見第參項），並同時報告
   `t_event − t_crit` 與 `t_event − 首次警報日` 兩個量
4. 若修正後提前期仍超過一年，須在結果中明白標注其為模擬設定之產物，不得對外宣稱

定態期的存在還有一個好處：它讓「翻轉型在漂移開始前與線性型難以區分」成為可檢驗的性質，
而那正是本研究主張的核心。
