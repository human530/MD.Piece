# 疾病軌跡模型 建置提示詞 v1

**用途**：交給 AI 程式助理，請它產生本研究階段二至階段四的可執行程式。
**日期**：2026-08-17

---

## 使用前必讀

這個模型不是用提示詞「生成」出來的，它是一段程式。提示詞的作用是讓 AI 幫你寫出這段程式，
而你仍然必須自己檢查它有沒有寫錯。最容易被寫錯、而且看起來完全正常的三件事是：

1. **標籤洩漏**：用來分群的特徵裡混進了結果變項，導致分群完美但毫無意義。
2. **循環論證**：模型學到的是你自己寫進生成器的規則，卻被當成發現。
3. **事後挑選**：AI 會傾向調參數直到結果好看，而那正是本研究要避免的。

因此下方提示詞中對這三點都有明確的禁止條款，請勿刪除。

## 主提示詞（可直接複製）

```
你是一位研究工程師。請用 Python 實作一個疾病軌跡模擬與分析流程，
用於檢驗三項假說。請嚴格照規格做，不要自行「改良」或簡化，
遇到規格不清楚的地方請先問我，不要自己假設。

# 研究背景（決定了下面每一項設計，請先讀懂再動手）

現行慢性病風險工具輸出「十年內發病機率」這一個數字。本研究要問：
同一個風險分數底下究竟有幾種不同的病程走法；把軌跡資訊納入預測後，
改變的是排序準確度還是介入的對象與時機；以及早期預警的價值是否
集中在特定的軌跡型態上。

三項假說：
H1 同一風險分數區間內存在數量有限但可區辨的多種軌跡型態。
H2 軌跡資訊對鑑別力的增益有限（預期 C 指數增益在 0.01 以內），
   但會顯著改變高風險族群的組成與建議介入時點。
H3 在具雙穩態特性的「翻轉型」軌跡上，早期預警指標的偵測提前期
   顯著長於「線性爬升型」；爬升型上預警相對於單純追蹤趨勢無額外價值。

# 模組一：合成世代生成器

產生 N 位虛擬個案（預設 N=3000），每位有：
- 基線特徵：年齡、性別、基礎指標值、一個潛在易感度
- 一條長度 T 天的疾病活動度序列 x(t)（預設 T=1825，即五年，日解析度）
- 一個已知的事件時點（若未發生則標記為右設限）

個案依生成機制分為兩大類，比例可設定（預設各半）：

（甲）線性爬升型
  x(t) = x0 + slope * t + 雜訊
  slope 由數個子類別的參數決定，子類別數、比例與斜率由外部參數檔指定
  （這些參數應來自已發表文獻，不要自己編；參數檔格式見模組零）

（乙）翻轉型（雙穩態）
  以隨機微分方程生成：dx = (-x^3 + x + mu(t)) dt + sigma dW
  mu(t) 由 mu_start 線性漂移至個案專屬的 mu_end
  臨界值 mu_c = 2/(3*sqrt(3)) ≈ 0.3849
  當 mu(t) 首次跨過 mu_c 的那一天，記為該個案的「已知臨界日」

【重要】翻轉型個案的臨界日必須被記錄下來，這是真實資料無法提供的，
也是整個研究非得先在模擬上做的理由。不要省略這個欄位。

以 Euler-Maruyama 法積分，每日取 10 個子步，記錄每日值。
所有隨機性由單一 seed 控制，且 seed 必須是參數。

# 模組零：外部參數檔

生成器讀取一個 JSON 參數檔，內含各軌跡子類別的類別數、人數比例、
斜率或漂移速率，以及每一列的文獻出處欄位（字串）。
程式啟動時應檢查每一列都有出處，缺少者印出警告。
這是為了確保模擬不是憑空設定。

# 模組二：基線風險分數與分層

以基線特徵（不含任何未來資訊）計算一個十年風險分數。
可用簡單的 logistic 形式，係數由參數檔指定。
【禁止】不得使用 x(t) 在基線之後的任何值來計算基線分數。

依風險分數分層，同時產生五分位與十分位兩套分層，後續分析在層內進行。

# 模組三：軌跡分群（對應 H1）

在每一個風險層內，對該層個案的 x(t) 序列做分群：
- 方法 A：群組軌跡模型（可用多項式基底的有限混合模型）
- 方法 B：對序列特徵做 k-means（特徵：水準、斜率、曲率、變異度）
- 兩種方法各自決定最佳群數，準則為資訊準則加上分群穩定度
- 穩定度以 bootstrap 計算：重抽 200 次，統計同一對個案落在同一群的比例
- 以置換檢定確認群數顯著大於一：把序列的時間順序隨機打亂後重跑，
  比較真實資料的分群品質是否超過置換分布的 95 分位

輸出：每層的群數、各群比例、穩定度、置換 p 值、以及代表性軌跡圖。

# 模組四：靜態對動態預測（對應 H2）

建立兩套預測並比較：
- 靜態：只用基線特徵，配適一次
- 動態：地標分析。在數個地標時點（例如第 180、365、730 天）
  各自重新配適，使用該時點之前的所有可得資訊（含 x(t) 的歷史）

比較指標分兩組：
第一組（預期增益有限，但仍須報告）：C 指數、Brier 分數
第二組（本研究重點）：
  - 淨重新分類比例：加入軌跡資訊後被移出或移入高風險組的個案比例
  - 建議介入時點位移：兩套預測首次判定為高風險的日期之差，
    以中位數與四分位距報告

【重要】若你發現動態預測的 C 指數大幅提升（超過 0.05），
請停下來檢查是否有標籤洩漏，不要直接回報好結果。

# 模組五：預警的型態依賴（對應 H3）

在每位個案的序列上以滾動窗計算：
- 一階自相關 AR(1)（先去趨勢再計算）
- 滾動標準差
- 以 Kendall tau 檢定兩者是否呈上升趨勢
- 顯著性以區塊置換產生虛無分布（不可用一般的 t 檢定，序列相依會造成假陽性）

警報規則在分析前寫定（例如：AR(1) 與 SD 的 tau 同時超過置換分布 95 分位）。

對每位個案計算：
- 偵測提前期：首次警報日至已知臨界日的天數（僅翻轉型有臨界日）
- 偽警報率：每人每年未對應真實事件的警報次數

分別統計翻轉型與爬升型，並以置換檢定比較兩型的提前期差異。
【重要】檢定一律雙尾。已有研究報告某些情境下轉折前變異度反而下降，
不得預設方向。

# 模組六：敏感度與穩健度

下列參數以格點掃描，全部結果都要輸出，不得只挑好看的：
- 滾動窗長：14、21、28、42 天
- 去趨勢方式：高斯核平滑、線性、不去趨勢
- 風險分層：五分位、十分位
- 分群方法：A 與 B 各跑一次
- 隨機種子：至少 5 個，報告平均與範圍（不是只報最好的那個）

# 輸出規格

- results.json：所有數值結果，含每個參數組合
- figures/：至少五張圖
  1. 單一翻轉型個案的 x(t) 與其滾動 AR(1)、SD（標出已知臨界日）
  2. 各風險層的軌跡型態分布
  3. 靜態對動態的 C 指數與淨重新分類對照
  4. 建議介入時點位移的分布
  5. 翻轉型與爬升型的提前期比較
- 所有圖使用黑白灰，不使用彩色，字型可讀，座標軸有單位

# 禁止事項（請逐條遵守，這些是本研究的方法學核心）

1. 禁止用未來資訊計算基線分數或基線特徵。
2. 禁止在看過結果之後回頭調整分群數、窗長或警報閾值。
   若你認為某個設定不合理，請告訴我，由我決定是否改，不要自己改。
3. 禁止只報告有利的種子或參數組合。
4. 禁止把「模型學到生成規則」當成發現。若某個結果好得異常，
   請主動指出它可能只是反映了生成器的設定。
5. 禁止使用單尾檢定。
6. 禁止在沒有出處的情況下自行填入軌跡參數。

# 程式風格

- 單一入口點，參數全部可由命令列或設定檔指定
- 每個模組獨立可測，並附至少一個單元測試
- 註解說明「為什麼這樣做」而非「這行在做什麼」
- 不使用需要付費或需申請的外部服務

請先回覆你對這個規格的理解，並列出你認為最容易出錯的三個地方，
確認之後我們再開始寫程式。
```
