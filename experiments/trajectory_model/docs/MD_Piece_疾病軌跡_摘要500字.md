# 疾病軌跡研究計畫整合摘要

**≤500 字・定位方向說明・2026-08-17**

定位一句話：十年風險分數把一整條病程壓成一個數字；同樣百分之十五的兩個人，一個慢慢爬、一個突然翻，而分數看不出差別。

為何值得做。丹麥全國資料已萃取出 1,171 條疾病軌跡；腎功能下降更分出四型，斜率相差約四倍，證明同一終點可以有完全不同的走法。但既有研究把軌跡當成地圖，沒有回頭問：一個風險分數底下究竟藏了幾種路。

誠實前提。文獻顯示把軌跡與變異度納入預測，C 指數僅由 0.651 升至 0.659。故本研究不主張軌跡能提升準確度，而主張它改變的是「該對誰、在什麼時候行動」。

三個假說。H1：同一風險區間內存在三至四種可區辨的軌跡型態。H2：鑑別力增益有限，但高風險族群的重新分類比例與建議介入時點位移顯著不為零。H3：預警的價值集中於翻轉型軌跡；對線性爬升型而言，預警相對於單純追蹤趨勢並無額外價值。

怎麼做。三階段，且前三階段完全不需個人層級病歷。一，以公開軌跡瀏覽器（720 萬人、1.22 億次住院）取得疾病路徑結構，並彙整已發表分類的參數。二，以這些參數播種合成世代，做軌跡分群與靜態對動態預測的比較。三，分別產生翻轉型與爬升型，比較臨界減速指標的提前期與偽警報率。真實資料驗證列為未來工作。

界線。軌跡類別以文獻參數重現而非重新發現；模擬中的雙穩態為我方寫入，不可反推真實疾病必然有分岔；本研究不做診斷、不取代醫師。
