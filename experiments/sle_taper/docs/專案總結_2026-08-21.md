# SLE 狼瘡腎炎減藥翻轉預警——專案總結（2026-08-21）

依《研究計畫書 v2》（2026-08-18，主）與 v1（輔）建置完成；工作規則沿用《ClaudeCode 全案建置指示 v1》。
全部程式與結果在 `experiments/sle_taper/`（branch `claude/disease-trajectory-model-prompts-ad24d8`，PR #605）。

## 一、研究問題

狼瘡腎炎病人長期緩解後能否停用免疫抑制劑，目前最可靠的判斷是再做一次腎切片（De Rosa 2018：敏感度 1.00、特異度 0.88，
但需侵入性穿刺）。核心問題：**減藥期間頻繁而低精度的非侵入監測，能否讀出目前僅切片可得的資訊**——理論依據是臨界減速
（系統越接近翻轉邊緣，受擾動後恢復越慢，可由時間序列的 AR(1)／SD 上升偵測）。

## 二、假說的演變

**v1 四項假說（事前寫定）**：H1 減藥後軌跡型態可辨；H2 時序資訊的 C 增益有限（<0.05）但顯著改變高風險名單；
H3 翻轉型的預警提前期 > 逐步惡化型；H4 高頻低精度可逼近單次高精度侵入測量（交換率）。

**v2 重構（現行主軸）**：不再以「發現型態」為問題，改為**已知六種競爭機制下、固定假警報負擔的機制別操作特性**：
在每病人年假警報 ≤ 0.1 的代價下，警報規則對各機制抓得到多少、提前多久、在什麼取樣條件下失效（可辨識邊界）。
分群降為次要探索；v1 閘門 G1/G3 因此移除。次要問題保留：減藥放慢是否延長預警窗口。

## 三、模型

### 生成層（合成世代，每個數字有出處）
- 動力學：dx = (1/τx)(−x³ + x + μ(t))dt + s·ξ(t)dt；ξ 為單位變異 OU（相關時間 τξ）；μ(t) = μᵢ − g_eff(t)；μc = 2/(3√3) ≈ 0.385
- 暴露：g_eff = 一階藥動滯後（21 天）∘（處方排程 × 依從［個人係數＋隨機中斷］）；減藥排程 180 天線性（**佔位**）
- 六機制（標籤已知）：分岔翻轉 22%／隨機越障 4%／連續惡化 5.1%（=Ning 持續下降型）／外生衝擊 4%／雜訊放大 5%／穩定 60%
- 基線特徵只透過「機制歸屬機率」與結局相關（κ=0.5 傾斜），不改機制內動力學
- 發作：λ(t) = λ0·e^{3x} 風險過程（λ0 校準）；跳轉里程碑 t_jump = x 首次跨 0（**佔位門檻**）
- 切片臂：B = q[x(t₀), μᵢ, 慢性化, 病程] + εB——不是直接觀測 μ；效能校準到 De Rosa 計數的 Clopper–Pearson 95% CI
- 觀測情境：規則／不規則回診／症狀驅動取樣／治療悖論（觀測異常→加藥→反事實重生成）／UPCR 映射＋檢測下限

### 分析層（評估工作台實際計算的兩條線，分開呈現不合成）
- **靜態**：logistic p = σ(−3.886 + 0.006·ln UPCR + 0.005·eGFR − 0.012·C3 + 0.210·ln dsDNA + 1.297·ln 病程 + 0.523·發作次數)，
  校準世代配適一次鎖定；獨立測試 C = 0.711
- **動態**：60 天窗去趨勢 → AR(1)、SD → 各自前綴 Kendall τ → S(t) = min(τ_AR1, τ_SD) → 累計最大 ≥ 0.667 即達警報條件；
  門檻由校準集穩定機制序列以假警報負擔 0.1/病人年鎖定（達成 0.108），非手設

## 四、校準與防作弊

三步校準全達標：λ0 = 2.445×10⁻⁴（24 個月發作率 0.289 ∈ [WIN-Lupus 0.273, De Rosa 0.306]；52 週 0.165 vs Gopal 0.321 偏差照實記錄）；
切片臂 εB = 0.4 → 0.942/0.860（範圍內）；靜態 C = 0.711 ∈ [0.65, 0.75]。
校準（seed+1000 族）與測試（seed+5000 族）分離；閾值鎖定含雜湊。
**六道品質關卡全過**：Q1 機制獨立（簽章＋打亂雜湊不變）、Q2 零信號（β=0 → AUC≈0.5、max|mean ΔC|=0.0076<0.01）、
Q3 閾值鎖定、Q4 時間方向、Q5 觀測密度、Q6 結局盲化（合成階段 N/A）。12 項單元測試全綠。

## 五、主要結果（n=3000 × MC5，預設情境：每週取樣、小誤差）

| 規則（同負擔 0.1/py） | 分岔敏感度（跳轉前） | 提前中位 | 對非分岔機制 |
|---|---|---|---|
| 聯合警報（臨界減速） | 0.241 | 185 天（至臨界 137 天） | 特異性佳：雜訊放大觸發 0.21 ≈ 穩定 0.21 |
| 水準規則（只看數值） | 0.527 | 19 天（至臨界 −29 天，晚於臨界） | 雜訊放大假觸發 0.77、連惡 0.83 |
| 趨勢規則（斜率外推） | 0.514 | 174 天 | 中等 |

核心交換關係一句話：**臨界減速規則抓得少但抓到就很早、對假訊號機制最有抵抗力；水準規則抓得多但幾乎是「事後」且大量誤報。**

- H2 對應：地標 90/180/365/540 天動態 C 增益 +0.124/+0.187/+0.254/+0.260、同風險集 NRI 0.21–0.54。
  ※ 主動標注：增益遠大於 v1 預期（<0.05），很可能是生成器設定所致（風險直接由 x 驅動，近期序列天然高度資訊），
  屬「在本模擬設定下」的甲級陳述，不得外推。
- 可辨識邊界（grid，14 軸＋48 格、3.3 小時）：**每月取樣敏感度全零**（60 天窗湊不滿 6 點）；每日≈每週（0.18–0.30）；
  窗 120 天可到 0.354；τx 14–90 天差異小；量測誤差 0→0.30 影響次於取樣間隔——**密度比精度重要**（H4 方向的甲級答案）；
  全圖低於切片臂敏感度 0.94（等值線不存在，如實不畫）。
- 減藥 540 天（頁內模擬）：提前期 213→400 天——減藥放慢延長預警窗口（次要問題，佔位排程下）。
