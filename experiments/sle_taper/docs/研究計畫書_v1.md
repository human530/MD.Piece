**狼瘡腎炎減藥期間的翻轉預警**

**以恢復速度取代侵入性切片的可行性研究**

版本 v1　日期 2026-08-17　文獻查證 PubMed，2026-08-17

**摘要**

狼瘡腎炎病人在長期緩解後能否停用免疫抑制劑，目前最可靠的判斷方式是再做一次腎切片。該方法準確，但需要穿刺。本研究以雙穩態動力系統描述腎臟疾病活動度，將減藥視為對系統穩定性的緩慢移除，並檢驗一個問題：在減藥期間頻繁而低精度的非侵入監測，能否讀出目前僅切片可得的資訊。研究以合成世代進行，不涉及真人，先確認方法在已知答案的條件下是否成立。預期產出並非更高的準確度，而是一條精度與頻率之間的交換率，以及一組「此訊號在什麼條件下不存在」的界線。

**壹、研究動機**

慢性病管理長期依賴單一時點的檢驗數值。同一組數值底下，病程走法可能完全不同，而現行工具無法區分。

狼瘡腎炎把這個問題呈現得特別清楚。Ning 等 2026 對 215 位切片確診病人建立軌跡模型，發現有一群人（佔 7.0%）基線腎功能反而較好，卻在後期急轉直下；同一研究指出，48% 的長期惡化者曾在十二個月內達到完全蛋白尿反應。短期看起來最好的，未必是長期最好的。

更具體的臨床困境在維持治療該用多久。De Rosa 等 2018 讓 44 位長期緩解病人停藥並前瞻追蹤二十四個月，36 位完成，11 位發作；以第二次腎切片的活性指數建立的預測式，敏感度 1.00、特異度 0.88。判斷方法有效，但代價是侵入性穿刺。

**貳、研究目的與假說**

**一、核心問題**

減藥期間的動態資訊，能否非侵入地提供目前僅切片可得的判斷依據。

**二、機制假設**

以雙穩態系統描述腎臟疾病活動度 x。緩解與活動性腎炎各為一個穩定狀態，中間有能障相隔。免疫抑制治療將系統壓在緩解側；減藥使能障降低，內在疾病驅動力足夠強者翻轉至活動側。

系統越接近翻轉邊緣，受擾動後恢復越慢。此性質稱為臨界減速，可由頻繁量測的時間序列估得，不需知道絕對數值是否準確。

**三、四項假說（事前寫定，不得事後修改）**

**表1　假說與事前預測**

| 編號 | 假說 | 事前預測 |
| ----- | ----- | ----- |
| H1 | 減藥起點臨床上不可區分的族群中，存在數量有限但可區辨的減藥後軌跡型態 | 支持，惟群數可能不穩定 |
| H2 | 納入減藥後時序資訊，對是否發作的鑑別力增益有限，但顯著改變高風險名單組成與建議加強監測的時點 | C 指數增益小於 0.05；重新分類比例顯著 |
| H3 | 翻轉型上臨界減速指標的偵測提前期顯著長於逐步惡化型；逐步惡化型上預警相對趨勢外推無額外價值 | 支持 |
| H4 | 高頻低精度的非侵入監測可逼近單次高精度侵入測量，且兩者間存在可刻畫的交換率 | 方向未定，兩種結果均照實報告 |

**四、次要問題**

減藥速度放慢，是否延長可預警的窗口。此問題具直接臨床可操作性。

**肆、研究方法**

**一、模型**

腎臟疾病活動度依下式演變：

dx \= (1/τ)(−x³ \+ x \+ μ(t)) dt \+ ξ(t)

μ(t) \= μ內在 − g(t)

其中 ξ 為有色雜訊，τ 為系統鬆弛時間。μ內在為個體的內在疾病驅動力，不可直接觀測，僅腎切片可帶誤差測得；g(t) 為免疫抑制的穩定效果，依減藥排程遞減，屬已知資訊。臨界值 μc \= 2/(3√3) ≈ 0.3849。

減藥使 μ 上升。μ內在較低者即使完全停藥仍不跨越臨界，屬可安全停藥者；較高者於減藥途中翻轉。臨床決策即為區分兩者。

必須使用有色雜訊。 若逐步惡化型採用白雜訊，其自相關恆為零，H3 將成為構造上必然成立的結果而非發現。

**二、兩條對照臂**

**表5　兩臂設定**

| 臂 | 觀測方式 | 對應現實 |
| ----- | ----- | ----- |
| 切片臂 | 單次、低誤差、直接觀測內在驅動力 | 重複腎切片 |
| 非侵入臂 | 高頻、高誤差、僅觀測活動度序列 | 抽血與尿液監測、平台自填 |

兩臂比較為本研究的核心結果。

**三、校準程序**

**表6　三步校準**

| 步驟 | 校準對象 | 目標值 | 來源 |
| ----- | ----- | ----- | ----- |
| 一 | 內在驅動力之分布 | 完全停藥後 24 個月發作率約 0.31 | De Rosa 2018 |
| 二 | 切片臂之量測誤差 | 使門檻規則之敏感度接近 1.00、特異度接近 0.88 | De Rosa 2018 |
| 三 | 基線靜態模型 | C 指數落在 0.65 至 0.75 | 慢性病風險模型之常見區間 |

步驟二使切片臂成為被校準至已發表預測式的對照，而非憑空設定。

**四、指標與檢定**

滾動一階自相關與滾動標準差，先去趨勢再計算；以 Kendall τ 檢定其上升趨勢。顯著性由區塊置換建立的共同虛無分布決定（抽 200 位，每位 100 次，共 20,000 個虛無值）。

主警報規則為兩項指標的 Kendall τ 同為正且皆超過虛無分布第 95 百分位，屬單尾向上；下降型偏離獨立計數但不計入主要提前期。假設檢定一律雙尾。

置換檢定的虛無假設為「序列的時間順序不帶資訊」，非「序列無變異」，此語意須於報告中明白說明。

**柒、限制與不宣稱事項**

**表9　本研究不宣稱之事項**

| 不宣稱 | 理由 |
| ----- | ----- |
| 任何絕對提前天數 | 該數值由模擬設定決定 |
| C 指數增益之絕對大小 | 取決於結局之定義方式 |
| 可用於真實個人 | 現階段無任何真人資料 |
| 任何減藥時機或速度之建議 | 屬醫療決策，非本研究範圍 |
| 可取代腎切片 | 至多為縮小需切片之範圍，兩者非同一等級之主張 |

其他限制：本框架僅涵蓋已達臨床緩解、正考慮停藥之族群，人數有限；其軌跡為治療反應軌跡而非自然病程，推廣性受限。

範圍聲明：本研究之分析對象為程式生成之合成序列，參數取自已發表文獻之彙總統計。全程未招募受試者、未進行人體測量、未使用任何個人層級健康紀錄，不構成人體研究，無需倫理審查。所有結果均為模擬設定下之相對比較，不構成臨床主張。本系統不做診斷，不取代醫師判斷。
