# SLE 狼瘡腎炎版核心切換 摘要

**日期**：2026-08-17　**字數**：約 480 字

---

本研究核心自一般慢性腎臟病切換至狼瘡腎炎減藥翻轉。

切換理由有三。其一，翻轉型在文獻上實際存在：Ning 2026 於 215 位切片確診
class III/IV 狼瘡腎炎中，以潛在類別軌跡模型得到晚期下降型佔 7.0%，
該型基線腎功能反而較高、91% 有蛋白尿發作，起點最健康卻後期垮掉，
不必如原版自災難型描述硬推。其二，該研究結論即本研究前提：
48% 的腎功能惡化者曾達完全蛋白尿反應，短期反應無法預測長期結局。
其三也最關鍵，減藥是有排程、有紀錄的動作，
等於把「參數緩慢掃過臨界」這個臨界減速理論的前提實際執行出來，
使本題成為受控的分岔實驗，而非假設。

模型改寫的核心是把 μ 拆為內在疾病驅動力減去免疫抑制效果。
前者不可觀測、僅腎切片能帶誤差測得；後者依減藥排程已知。
於是個體未知量由一組收斂為一個，研究問題也隨之明確化為：
在減藥過程中觀察活動度的動態，能否非侵入地估出那一個量。

臨床對照基準明確。De Rosa 2018 以第二次腎切片的活性指數建立預測式，
敏感度 1.00、特異度 0.88，但代價是侵入性穿刺。
本研究因此成為一個交換問題：高頻低精度的非侵入監測能逼近它多少。
原版列為選用的精度—頻率實驗，在本版升格為核心假說。

方法學骨架全部保留，包含三道閘門、群數雙準則、警報單尾而檢定雙尾、
有色雜訊、起點重疊、風險驅動結局與陰性結果處理規則，
另新增第四道閘門，確保內在驅動力不得洩漏進非侵入臂。

本版另生一個具臨床可操作性的次要問題：減藥減得多慢，才來得及預警。

現階段全為合成資料，無真人、無倫理審查需求，不構成臨床主張。
四項參數缺口（發作定義、減藥排程、監測頻率、各類別斜率）動工前須查證補齊。
