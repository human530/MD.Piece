# 第一部　研究內容（先讀懂再動手）

## 一之一　問題

狼瘡腎炎的維持治療該用多久，長期缺乏前瞻證據。
臨床上看起來同樣穩定的病人，減藥之後有人平安、有人發作，
而目前最可靠的區分方法是再做一次腎切片——準確但侵入。

## 一之二　機制假設

以雙穩態系統描述腎臟疾病活動度 x：

- x ≈ −1 為緩解狀態（穩定）
- x ≈ +1 為活動性腎炎狀態（亦穩定）
- 兩者之間有能障隔開

免疫抑制治療的作用是把系統壓在緩解側。
減藥使能障降低；若降到臨界以下，系統翻轉至活動側。

**關鍵**：減藥是有排程、有紀錄的動作。
臨界減速理論成立的前提是「參數緩慢掃過摺疊分岔」，
而減藥正是把這個掃描實際執行出來。本題因此是受控的分岔實驗。

## 一之三　四項假說

| # | 假說 | 事前預測（先寫死，不得事後改） |
|---|---|---|
| H1 | 在減藥起點臨床上不可區分的族群中，存在數量有限但可區辨的減藥後軌跡型態 | 支持，但群數可能不穩 |
| H2 | 納入減藥後時序資訊，對「是否發作」的鑑別力增益有限，但顯著改變高風險名單組成與建議回頭加藥的時點 | ΔC < 0.05；重分類顯著 |
| H3 | 翻轉型上臨界減速指標的提前期顯著長於逐步惡化型；逐步惡化型上預警相對趨勢外推無額外價值 | 支持 |
| H4 | 高頻低精度的非侵入監測可逼近單次高精度侵入測量，且存在可刻畫的交換率 | 方向未定，兩種結果都要報 |

## 一之四　次要問題

減藥減得多慢，才來得及預警。
此問題具直接臨床可操作性，列為次要結果，不得省略。

## 三之二　計算方式（逐式）

### 動力學

    dx = (1/τ) · (−x³ + x + μ(t)) dt + ξ(t)

    μ(t) = μ_intrinsic − g(t)

    ξ 為 Ornstein–Uhlenbeck 有色雜訊：
        dξ = −(1/τ_OU) ξ dt + σ √(2/τ_OU) dW

積分法：Euler–Maruyama，每日 10 子步，記錄每日值。

**必須用有色雜訊。** 若用白雜訊，逐步惡化型的自相關恆為零，
「翻轉型自相關會升、逐步型不會」就成為構造上必然成立，不是發現。

### 各量的意義與可觀測性

| 符號 | 意義 | 誰看得到 |
|---|---|---|
| `x(t)` | 腎臟疾病活動度 | 兩臂皆可，帶量測誤差 |
| `mu_intrinsic` | 內在疾病驅動力 | **僅切片臂**，帶誤差 |
| `g(t)` | 免疫抑制穩定效果 | 兩臂皆可（用藥紀錄） |

### 觀測層（與生成層分開）

真實序列不變，只改「看得到的版本」：

    x_obs[i, t] = x[i, t] + N(0, σ_meas²)      若 t 為取樣日
    x_obs[i, t] = NaN                           否則

量測誤差加在觀測層，不得加在生成層。此區分是 H4 的前提。

### 指標計算

| 指標 | 計算方式 |
|---|---|
| 滾動 AR(1) | 先去趨勢，再於長度 `window` 的窗內計算 lag-1 自相關 |
| 滾動 SD | 同窗內標準差，去趨勢後 |
| 趨勢檢定 | Kendall τ，取截至該日的完整指標序列 |
| 虛無分布 | 抽 `null_subjects` 位，每位做 `null_perms` 次區塊置換（區塊長 = `window`），共同分布 |
| 主警報 | AR(1) 與 SD 的 Kendall τ **同為正**且皆 > 虛無分布第 95 百分位（單尾向上） |
| 下降型偏離 | 兩者同為負且超過 95 分位；**獨立計數，不計入主要提前期** |
| 提前期 | 同時算 `t_event − 首次警報日` 與 `t_crit − 首次警報日` |
| 偽警報率 | 每人每年未對應事件之警報次數；burn-in 期自分母扣除 |
| C 指數 | 各地標時點分別計算 |
| 淨重新分類 | 絕對閾值（≥ 整體事件率）與相對閾值（前 20%）兩種都算 |
| 時點位移 | 兩套預測首次判定高風險之日期差，**回傳整個陣列**，不得只回摘要統計 |

### 虛無假設的語意（須寫入註解與方法）

時間打亂保留水準與總變異，因此檢定的虛無假設是
「該序列的時間順序不帶資訊」，而非「該序列無變異」。

## 三之三　事件生成

事件為風險驅動，不是門檻跨越：

    λ(t) = λ₀ · exp(β · x(t))

`t_threshold`（x 跨臨床門檻）仍然記錄，但僅作為描述性里程碑。

四個時點分開儲存，不得合併：
`t_onset`（減藥起始日，已知）、`t_crit`（μ 首次跨 μ_c）、
`t_threshold`、`t_event`。

## 三之四　校準程序（本版核心，請照順序做）

### 步驟一：校準 μ_intrinsic 的分布

調整 `mu_intrinsic` 的分布，使**完全停藥後 24 個月的發作率**
落在 0.306 附近（De Rosa 2018）。

檢核：52 週的發作率應接近 0.321（Gopal 2023）。
兩者若無法同時滿足，以 24 個月為主，並在 `assumptions.md` 記錄偏差。

### 步驟二：反推 σ_biopsy

切片臂觀測 `mu_intrinsic + N(0, σ_biopsy²)`，並以一個門檻規則判定發作與否。

調整 `σ_biopsy` 與門檻，使該規則的敏感度接近 1.00、特異度接近 0.88
（De Rosa 2018 的預測式效能）。

**這一步的意義**：切片臂不是憑空設定的對照，而是被校準到
一條真實發表過的預測式。非侵入臂之後才有東西可比。

### 步驟三：校準靜態基線

僅用基線特徵的靜態模型 C 指數應落在 0.65 至 0.75。
過高代表基線特徵被設定得過度資訊化，H2 的比較基準會失真。

三步的實際達成值須於程式啟動時列印。

## 三之五　四道閘門

生成世代之後、任何分析之前執行。任一未過即中止並印出實際數值。

| 閘門 | 檢核 | 通過條件 | 未過代表 |
|---|---|---|---|
| G1 | 各風險層內單一型別最高佔比 | ≤ 0.90 | 起點未重疊，H1 被設定成偽 |
| G2 | 令 β = 0 重跑最小版 M4 | \|ΔC\| < 0.01 | 結局仍與 x(t) 耦合，存在洩漏 |
| G3 | 僅用 t < t_onset 資料訓練型別分類器 | AUROC ∈ [0.45, 0.55] | 兩型在減藥前即可分，存在混淆 |
| G4 | `mu_intrinsic` 是否進入非侵入臂任何特徵 | 完全未進入 | H4 的比較失去意義 |

G4 為本版新增。實作方式為在非侵入臂的特徵建構函式簽章中
完全不傳入 `mu_intrinsic`，並寫一個測試確認該欄位不在特徵矩陣的來源鏈上。

## 三之七　單元測試（至少這些）

1. 同 `master_seed` 兩次呼叫產生相同串流；新增模組索引不位移既有串流
2. `ou_noise` 的實測自相關時間常數接近設定值（容許 10%）
3. μ 恆低於 μ_c 時，長時間跨越比例低於設定上限
4. `t_crit` 定義正確：μ 首次跨 μ_c，非 x 跨 0
5. β = 0 時事件時間與 x 獨立
6. 觀測層加噪不改變生成層陣列（以雜湊比對）
7. 定態期（t < t_onset）兩型的線性趨勢斜率無顯著差異
8. `noninvasive_arm` 的呼叫鏈中不存在 `mu_intrinsic`
9. 決定性：同 seed 連跑兩次，results.json 逐位元相同
10. 換一組假的疾病參數可跑通整條管線（證明程式與疾病無關）

| 基線臨床設定 | 蛋白尿、腎功能、補體、抗體、病程年數、既往發作次數 |
| 病理設定（可略） | 切片分型、活性指數、慢性化指數 |
| 監測設定 | 取樣間隔、量測誤差水準 |

進階區（預設收合）：τ、σ、映射權重、亂數種子。

每個欄位旁有資訊圖示，點開顯示：該欄位的合理範圍、
在模型中的作用、以及對應的出處與 `status` 標籤。

**病理設定這一組要特別標明**：它對應切片臂，
在真實世界需要腎穿刺才能取得。此說明固定顯示，不得摺疊。

### 區二　運算

一個「執行模擬」按鈕。
逐步狀態顯示實際動作名稱（讀取參數、標準化、生成序列、
取樣與加噪、計算指標、兩臂比較），不得用進度條配假文字。

### 區三　結果三層

第一層：模型輸出。一句話加一個數字。
  例：此組情境在模型中被歸為晚期翻轉型，機率 0.62。

第二層：這個數字怎麼來的。
  表格逐列列出參與運算的輸入項，欄位為
  輸入值、標準化值、權重、貢獻量；表下一行說明加總方式。

第三層：這些權重從哪裡來。
  每個係數掛 `status` 標籤，三種即第二部的三種，
  並即時統計：「本次運算使用 N 個係數：已錨定 a、待抽取 b、本研究設定 c」。

  **待抽取者若仍為佔位值，此處必須醒目標示，且結果區加註
  「本次結果使用佔位參數，不得對外引用」。**

### 區四　軌跡與兩臂比較

上方一張圖：模型依此情境生成的代表性序列，
標出減藥起始日、臨界日、門檻跨越日、事件日、首次警報日五個時點。

下方一張圖：切片臂與非侵入臂的比較，
以及精度—頻率 4×4 熱圖，含等值線（與「單次高精度」表現相同的組合）。

### 區五　說明

三段，每段不超過三句。

  第一段說明這張圖在畫什麼。
  第二段說明為什麼要看恢復速度而不是數值高低。
  第三段說明這個結果不代表什麼。

第二段須使用具體的日常現象作說明，全段每句不超過二十字，
不使用比喻性形容詞、不使用擬人化、不使用語助詞。

## 四之三　功能清單與優先序

| 優先 | 功能 |
|---|---|
| P0 | 情境輸入、執行模擬、結果三層、來源溯源與 status 計數 |
| P0 | 常駐說明列、佔位參數警示 |
| P0 | 軌跡圖含五個時點 |
| P1 | 兩臂比較圖、精度—頻率熱圖 |
| P1 | 減藥速度敏感度（多慢才來得及預警） |
| P1 | 本次工作階段的參數比較表（記錄使用者掃過哪些設定） |
| P2 | 匯出 JSON（輸入、輸出、參數雜湊、種子；不含任何身分資訊） |
| P2 | 深色模式 |

P1 的「參數比較表」有方法學用意：讓使用者看見自己掃過的參數空間，
避免只記得最後一次好看的結果。

## 四之四　邊界情況（逐項預先決定，不要臨場發揮）

| 情況 | 處理 |
|---|---|
| 輸入超出合理範圍 | 夾至邊界並顯示提示；不得靜默修改 |
| 欄位留空 | 標為未提供，說明對結果的影響；**不得以平均值默默填補** |
| 只有單點沒有序列 | 只跑切片臂，明白顯示非侵入臂不可用及原因 |
| 未提供病理設定 | 只跑非侵入臂，顯示切片臂不可用 |
| 使用者不知道減藥排程 | 提供三個文獻情境預設；不猜、不自動選 |
| 兩臂結論相反 | 兩個都顯示，**不得合成單一分數** |
| 模型算出高風險 | 顯示型態機率與模型位置；禁止燈號、禁止等第、禁止建議 |
| 使用者問「該不該減藥」 | 固定文案：本工具不回答此問題，請與醫師討論。此文案寫死 |
| 序列過短不足一個窗長 | 不計算滾動指標，說明所需最短長度 |
| 佔位參數尚未補齊 | 全程標示，結果區加註不得對外引用 |

## 四之五　技術規格

| 項目 | 規格 |
|---|---|
| 形式 | 單一 HTML，自含，離線可開 |
| 框架 | 不使用；原生 JS |
| 運算 | 全部瀏覽器端；不發任何請求；不寫任何儲存 |

| 決定性 | 同一組輸入永遠得到同一組輸出 |
| 字型 | 系統字型堆疊，中文優先 |
| 對比 | 符合 WCAG AA；顏色不得為唯一區分方式 |
| 鍵盤 | 全部控制項可操作 |
| 手機 | 單欄；圖可橫向捲動 |

## 四之六　文案規範

語氣設定為資深臨床工作者對病人說明檢驗結果：
句子短、每句只講一件事、用具體日常現象說明、
不加修飾性形容詞、不預測對方情緒、不替對方下決心。

### 禁用（出現即不合格）

驚嘆號；「讓我們一起」「接下來我們要」「首先」「總而言之」；
「很重要的是」「值得注意的是」；「太棒了」「別擔心」「放心」「請安心」；
「智慧」「賦能」「一站式」「全方位」「精準守護」；
以問句開場帶節奏；表情符號；「你的」「您的」「我的」。

### 對照

| 不合格 | 合格 |
|---|---|
| 讓我們一起看看您的減藥風險吧！ | 以下是模型依此組情境設定產生的結果。 |
| 這個數值非常重要，值得特別注意喔 | 這個數值決定模型把此組情境歸到哪一類。 |
| 別擔心，這不代表一定會發作 | 這是模型的輸出，不是預測，也不是診斷。 |
| 我們的智慧引擎精準分析 | 計算方式與每個係數的出處列在下方。 |

須附一支檢查腳本 `tools/lint_copy.py`，掃描介面文案並在踩到禁用語彙時失敗。

# 第六部　驗收清單

執行 `python run.py --verify` 應逐項檢查並輸出通過與否。

## 模型端

1. 決定性：同 seed 連跑兩次，`results.json` 逐位元相同
2. 四道閘門全過，且數值列印於 `assumptions.md`
3. `mu_intrinsic` 不在非侵入臂特徵的來源鏈上
4. 校準三步的達成值皆在目標區間，或偏差已記錄
5. 所有參數皆有 `source` 與 `status`
6. 換一組假疾病參數可跑通整條管線
7. 十項單元測試全過

## 介面端

8. 常駐說明列無法關閉
9. 隨機點五個顯示中的數字，皆能點到出處
10. `status` 三類計數正確且顯示於顯眼位置
11. 佔位參數存在時，結果區有不得對外引用之標註
12. 同一組輸入連按十次，輸出完全一致
13. 斷網後開啟仍完全可用
14. `tools/lint_copy.py` 通過（含「你的」「您的」檢查）
15. 僅用鍵盤可完成一次完整操作
16. 區五第二段每句在二十字以內
17. 搜尋全部文案，不存在減藥建議語句

# 第七部　禁止事項

1. 禁止用未來資訊計算基線特徵。
2. 禁止在看過結果後回頭調整任何參數或事前預測。
3. 禁止只報有利的種子或參數組合。
4. 禁止把「模型學到生成規則」當成發現。
5. 假設檢定禁止單尾。
6. 禁止在沒有出處的情況下填入任何數值。
7. 禁止在介面上提供任何減藥時機或速度的建議。
