## 貳、圖B　位能地景（機制層）

把雙穩態畫成一顆球停在山谷裡，四格顯示減藥四個階段。 免疫抑制效果 g(t) 遞減使 μ 上升，緩解側的谷底逐漸變淺， μ 超過 μc ≈ 0.385 之後該谷底完全消失，球必然滾向活動側。

這張圖不含任何資料，是純粹的機制說明圖。 它的用途是讓「恢復變慢」這件事變得可看見——谷底越淺，球被推開後回來得越慢。

## 參、圖A　機制展示廊（資料層）

六欄對應六種資料生成機制，三列分別為觀測序列、滾動 AR(1)、滾動 SD。 點虛線為減藥起始日，實線為發作日，每欄左下標該機制的發作率。

**這是本研究最重要的一張圖**，因為它一眼說明了為什麼需要競爭機制。

看第五欄「雜訊放大」：它的滾動 SD 從 0.06 一路爬到 0.32， 形狀跟第一欄「分岔翻轉」末端的上升幾乎無法用肉眼區分—— 但它的穩定性完全沒有改變，只是雜訊變大。 如果研究裡只有分岔與穩定兩組，這種序列會被判為預警成功，那是假陽性。

其餘各欄的作用：

| 欄 | 特徵 | 檢驗什麼 |
| :---- | :---- | :---- |
| 分岔翻轉 | 緩慢上升後跳轉，末端 SD 上升 | 正對照 |
| 隨機越障 | 早期即跳，無明顯前兆 | 沒有預警窗口的翻轉 |
| 連續惡化 | 穩定線性上升，SD 平坦 | 去趨勢與特異性 |
| 外生衝擊 | 平穩後突跳再回落 | 無法預警的發作 |
| 雜訊放大 | SD 大幅上升但無翻轉 | 變異數假警報 |
| 穩定未發作 | 全程平穩 | 虛無序列 |

## 肆、圖C　警報操作特性（效能層）

左圖為固定假警報負擔（穩定未發作者中 20% 曾觸發警報）下， 各機制的事前警報比例；右圖為首次警報至發作的提前期分布。

### 原型階段的結果與其解讀

**目前這組參數下，聯合警報規則沒有鑑別力。** 分岔翻轉的事前警報比例約 0.07 至 0.19，低於或等於 0.20 的假警報負擔； 表現最高的反而是雜訊放大（約 0.31）。

這個結果不應被當成「臨界減速在狼瘡腎炎無效」的結論，因為原型階段有三個已知缺陷：

1. **警報分數為自序列起點起算的累積 Kendall τ**，在整段期間反覆評估， 相當於多重比較；穩定序列的最大值本來就容易偏高， 使門檻被推到 0.867 這種極端值。正式版應改為固定近期視窗， 並以保留邊際分布與自相關的替代序列建立虛無。  
2. **AR(1) 在此取樣密度下飽和**。τx \= 40 天而取樣間隔 7 天， lag-1 自相關本來就在 0.85 以上，接近臨界時只能從 0.88 升到 0.90， 訊號被壓在天花板；本原型中帶訊號的其實是 SD 而非 AR(1)。 這一點本身就是可辨識地圖要回答的問題。  
3. **μ 掃過臨界的速度太快**。減藥 520 天而 μ 僅上升 0.22， 真正接近臨界的期間不到一百天，短於 180 天的滾動視窗。

第三點正好對應計畫書的次要問題：減藥減得多慢，才來得及預警。 原型的失敗方式，恰好指出正式版必須把減藥速度當成主要掃描軸。

## 伍、圖D　可辨識地圖（待補）

以取樣間隔（3／7／14／30／90 天）為橫軸、量測誤差（佔過程標準差 0／25／50／100%）為縱軸， 格值為固定假警報負擔下的事前警報比例，另加一條等值線標出 與「單次高精度切片」表現相同的組合。

此圖須待肆節三項缺陷修正後再產生，否則整張圖會是一片接近隨機的灰。
