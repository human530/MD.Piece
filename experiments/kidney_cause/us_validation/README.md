# 超音波佐證層（等待真實影像資料）

使用者要求以「上萬張腎臟超音波」佐證病因模型。**公開世界目前不存在**上萬張且可下載的腎臟超音波資料集
（最大公開集為數百張等級；scout 查證紀錄見 results/data_scout.json）。因此：

- 本目錄只定義**交換格式**與**一致性分析**，等真實影像（例如醫院 PACS 匯出）到位即可執行。
- `harness.py` 在沒有真實檔案＋出處帳本登錄時**拒絕執行**——不會生出任何假影像或假一致性數字。

## 交換格式（提供資料時照此擺放）

```
us_validation/data/
  manifest.csv        每列一張影像：
                      image_file, patient_key, exam_date,
                      us_cause_label(感染性/免疫性/代謝性/其他/未標),
                      us_findings(自由文字或編碼，如腎皮質回音增強/腎盂積水/囊腫…)
  images/…            對應影像檔（DICOM 或 PNG）
```

`patient_key` 需可對回檢驗資料的個案（去識別化對照表由資料提供方保管，不進本 repo）。

## 佐證分析（資料到位後 harness 會做的事）

1. **一致性**：血液模型的病因判定 vs 超音波標籤的 agreement（Cohen's κ、逐類混淆）。
2. **分歧解剖**：模型與超音波不一致的個案，其 biomarker 分佈與超音波 findings 的交叉表——分歧是資訊，不是誤差。
3. （若提供逐張標籤）以超音波為參考標準時血液模型的 AUC/敏感度/特異度，含 95% CI。

超音波影像本身的判讀模型（CNN 等）不在本層範圍——本層只做「血液模型 × 超音波標籤」的相互佐證。
