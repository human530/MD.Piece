# 醫院資料需求規格書 v1

腎損傷病因判別模型——切片／診斷世代

2026-09-01｜供 IRB 申請與資料萃取使用｜配套管線：`experiments/kidney_cause`

---

## 一、為什麼需要這份資料（一段話給 IRB）

本研究已以公開資料（NHANES，n=55,081）證明：常規血液檢驗對**感染性**腎損傷具中等判別力，
但對**免疫性**腎損傷**完全無法判別**（AUROC 0.575）。經解剖確認原因有二：
① 公開資料**無疾病診斷**，僅有血清學代理標籤；② 判別免疫性腎炎所需的檢驗
（補體 C3/C4、免疫球蛋白、抗 dsDNA、抗 PLA2R、ANCA）**公開資料皆未檢測**。
本階段擬以具**腎臟病理診斷**與**完整免疫檢驗**之醫院世代，檢驗同一假設。

## 二、標籤（本規格書最關鍵的一欄）

### （一）主標籤：腎臟病因診斷

| 欄位 | `dx_primary` |
|---|---|
| 來源 | **腎切片病理報告**（首選）或 腎臟科主治醫師病因判讀（次選，須另欄標明）|
| 格式 | 受控詞彙（見下），**不接受自由文字** |
| 時間 | 診斷日期 `dx_date` 必填 |

**受控詞彙（第一層：三大類）**

```
INFECTION   感染相關（HBV／HCV 相關腎病、感染後腎絲球腎炎、HIV 相關腎病…）
IMMUNE      免疫相關（狼瘡腎炎、IgA 腎病、膜性腎病、ANCA 血管炎、抗 GBM 病…）
METABOLIC   代謝相關（糖尿病腎病變、高血壓腎硬化、肥胖相關腎絲球病變…）
OTHER       其他（遺傳性、藥物性、阻塞性、不明…）
```

**受控詞彙（第二層：細項，`dx_secondary`，選填但強烈建議）**

```
IMMUNE:   LN_I..LN_VI（狼瘡腎炎 ISN/RPS 分級）、IGAN、MN、ANCA_GN、ANTI_GBM、
          MPGN、C3G、FSGS_PRIMARY、MCD
INFECTION: HBV_GN、HCV_CRYO、PIGN、HIVAN
METABOLIC: DKD、HTN_NEPHROSCLEROSIS、ORG
```

> **為什麼要細項**：本研究已證明「免疫」合併為單一類別時，狼瘡（C3↓）與類風濕（C3↑）
> 的訊號會互相抵消。細項標籤讓模型分別學習，是免疫軸能否成立的關鍵。

### （二）標籤品質欄位

| 欄位 | 內容 | 為什麼 |
|---|---|---|
| `dx_source` | `BIOPSY` / `CLINICAL` | 切片與臨床判讀的證據強度不同，須分層分析 |
| `dx_confidence` | `DEFINITE` / `PROBABLE` / `POSSIBLE` | 允許敏感度分析只用 DEFINITE |
| `biopsy_adequacy` | 腎絲球數 | <8 個腎絲球之切片診斷可靠度低 |

## 三、特徵（檢驗數值）

### （一）時序要求——本規格最重要的設計

```
所有檢驗值必須取自【診斷日期之前】的最近一次
       允許視窗：診斷前 0–90 天
       診斷後的檢驗值一律不得納入
```

**理由**：公開資料為橫斷面，本研究已證明其無法區分「暴露→腎病」與「腎病→測值改變」
（血鉛↑但尿鉛↓）。**診斷前檢驗**是本階段相對於公開資料的唯一根本優勢——若時序不對，
這份資料就退化成另一個 NHANES。

每筆檢驗附 `lab_date`，管線將自動驗證 `lab_date < dx_date` 並剔除違反者。

### （二）A 組：常規檢驗（與公開資料對齊，供跨資料比較）

| 類別 | 項目 |
|---|---|
| 生化 | 白蛋白、球蛋白、總蛋白、BUN、肌酸酐、尿酸、鈉、鉀、氯、鈣、磷、碳酸氫根、ALT、AST、ALP、GGT、總膽紅素、LDH、總膽固醇、三酸甘油酯、LDL、HDL、血糖 |
| 血球 | WBC 及五分類、RBC、Hb、Hct、MCV、MCH、MCHC、RDW、血小板、MPV |
| 尿液 | 尿蛋白／肌酸酐比（UPCR）、尿白蛋白／肌酸酐比（UACR）、尿液常規 |
| 發炎 | CRP |

### （三）B 組：免疫專項（**公開資料完全沒有的那一批**）

| 項目 | 對哪個細項最關鍵 | 必要性 |
|---|---|---|
| **補體 C3、C4** | 狼瘡腎炎、MPGN、C3G | ★★★ 必要 |
| **抗 dsDNA** | 狼瘡腎炎 | ★★★ 必要 |
| **ANA（含效價）** | 狼瘡 | ★★★ 必要 |
| **抗 PLA2R** | 膜性腎病 | ★★★ 必要 |
| **ANCA（MPO／PR3）** | ANCA 血管炎 | ★★★ 必要 |
| **抗 GBM** | 抗 GBM 病 | ★★ |
| 免疫球蛋白 IgG／IgA／IgM | IgA 腎病、單株免疫球蛋白病 | ★★ |
| ESR | 發炎活動度 | ★★ |
| 冷凝球蛋白 | HCV 相關 | ★ |
| 血清蛋白電泳／免疫固定 | 單株免疫球蛋白病 | ★ |

### （四）C 組：尿沉渣鏡檢

| 項目 | 為什麼 |
|---|---|
| 紅血球數／HPF、變形紅血球比例、紅血球柱狀體 | 區分腎絲球性 vs 非腎絲球性血尿——切片前最強的非侵入性線索 |

### （五）D 組：人口學與共病

年齡、性別、BMI、血壓、糖尿病史（含 HbA1c）、高血壓史、B/C 肝血清學、用藥清單（含起始日期）。

## 四、樣本數

依本研究於公開資料之實測教訓訂定：

| 教訓 | 數據 | 推論 |
|---|---|---|
| 感染類 35 例 → 169 例 | AUROC 由 0.876 **降至** 0.819 | 35 例的估計含 0.057 高估 |
| 梯度提升 vs 邏輯迴歸優勢 | 35 例時 +0.081，169 例時 −0.002 | 小樣本時複雜模型的優勢是過擬合 |

**最低要求**：每一個要宣稱效能的類別（第一層）**≥ 150 例**；
細項（第二層）若要個別報告，每項 **≥ 50 例**，否則僅做描述性統計。

**建議**：IMMUNE ≥ 300（因細項最多）、INFECTION ≥ 150、METABOLIC ≥ 300、OTHER 不限。

## 五、去識別化與交付格式

### （一）去識別化

- 病歷號以**單向雜湊**取代（研究方不持有對照表）
- 所有日期轉為**相對於診斷日的天數**（`lab_date` → `days_before_dx`）
- 年齡以 5 歲區間或 top-code 90 歲
- 不含姓名、地址、身分證字號、出生日期

### （二）交付格式：三張 CSV

```
patients.csv    一人一列
  pid_hash, age_band, sex, dx_primary, dx_secondary, dx_source,
  dx_confidence, biopsy_glomeruli_n, dm_history, htn_history

labs.csv        一人多列（長格式）
  pid_hash, lab_code, lab_name, value, unit, days_before_dx, lab_group(A/B/C)

meds.csv        一人多列
  pid_hash, drug_name, drug_class, days_before_dx_start, days_before_dx_stop
```

`lab_code` 請用院內代碼並附對照表；管線會自動對映至本研究的變數字典。

### （三）交付前自我檢查（給資料萃取人員）

```
□ 每位病人都有 dx_primary（受控詞彙，非自由文字）
□ 每筆檢驗 days_before_dx ≥ 0（診斷後的一律不要）
□ B 組免疫檢驗至少有 C3、C4、抗 dsDNA、ANA、抗 PLA2R、ANCA 六項
□ 各第一層類別人數 ≥ 150
□ 無任何直接識別欄位
```

### 事前登錄的效能預期（寫在看到資料之前）

依文獻錨點（PMID 38919623，具 anti-dsDNA＋補體之同型研究 AUC 0.880）：

| 軸 | 事前預期 | 若低於此值的解讀 |
|---|---|---|
| 免疫 vs 其餘 | 0.80–0.88 | 標籤品質或時序有問題 |
| 感染 vs 其餘 | 0.80–0.85 | 與公開資料一致 |
| 代謝 vs 其餘 | 0.80–0.85 | — |
| 免疫細項（狼瘡 vs 膜性 vs IgA）| 0.75–0.85 | 樣本不足 |

**不設 0.90 為目標。** 文獻最佳同型研究為 0.880，且其族群已限定為 SLE 腎侵犯者。

## 七、IRB 申請要點

| 項目 | 建議寫法 |
|---|---|
| 研究類型 | 回溯性病歷研究，去識別化資料，無介入 |
| 風險 | 最低風險；無直接識別資料離開院方 |
| 資料保存 | 去識別化資料存於研究者加密裝置，研究結束後 N 年銷毀 |
| 已完成之前期工作 | 公開資料分析（n=55,081）已界定假設與方法，本階段為驗證 |
| 預期貢獻 | 驗證常規＋免疫檢驗能否於切片前縮小病因範圍 |

## 八、一句話總結給合作醫師

> 我們已經用五萬人的公開資料證明：**沒有補體和自體抗體，免疫性腎病靠抽血看不出來**。
> 現在需要貴院**有切片診斷、且檢驗在切片之前**的病人資料，來驗證加上這些檢驗之後能做到多少。
> 我們要的不是「多」，是「切片前」——時序是這份資料唯一不可替代的價值。
